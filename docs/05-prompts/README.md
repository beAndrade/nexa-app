# Nexa AI Prompts

## Purpose

This directory contains the official prompts used during the development of the Nexa Platform.

Every prompt follows the architectural principles documented inside the project.

These prompts standardize the interaction between developers and AI assistants.

---

## Available Prompts

- Small Task
- Feature Development
- Bug Fix
- Code Review
- Refactoring
- Architecture Analysis
- Documentation Review
- Weekly Health Check

### Phase 2

A fonte oficial do workflow de produto é [Phase-2/00-phase2-system.md](./Phase-2/00-phase2-system.md).

O protocolo de QA é [Phase-2/08-validation.md](./Phase-2/08-validation.md).

O protocolo de Design & UX Review é [Phase-2/10-design-ux-review.md](./Phase-2/10-design-ux-review.md). Consulte quando a mudança tiver impacto de UI/UX: layout, texto visível, interação, estado vazio, erro, foco ou breakpoint.

O protocolo de Global Consistency Check é [Phase-2/11-global-consistency-check.md](./Phase-2/11-global-consistency-check.md). Consulte quando a mudança tocar ou dever seguir um padrão ou componente compartilhado, só nesse recorte.

O protocolo de Git Audit é [Phase-2/12-git-audit.md](./Phase-2/12-git-audit.md). Consulte antes do commit, em leitura, para conferir se a árvore contém só o escopo da unidade.

Este README não define outra sequência.
